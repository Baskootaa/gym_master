# Gym Master

نظام متكامل لإدارة الصالات الرياضية (Gym Management System).

## 📥 طريقة التشغيل:
1. قم برفع مجلد المشروع إلى سيرفر مح المحلي (مثل XAMPP أو Herd).
2. أنشئ قاعدة بيانات جديدة باسم `gym_master`.
3. قم باستيراد ملف قاعدة البيانات الموجود في المسار: `database/gym_master.sql`.
4. تأكد من ضبط إعدادات الاتصال بقاعدة البيانات في ملف الـ config الخاص بالمشروع.
